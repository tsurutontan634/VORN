# 京都市まちねこ活動支援事業 — 抜粋メモ（暫定）

出典：京都市HP https://www.city.kyoto.lg.jp/hokenfukushi/page/0000189400.html
および実施要綱（令和6年4月1日改正）。要綱PDF本文が sources/ に揃ったらそちらが優先。

## 制度の概要
- 事業名：京都市まちねこ活動支援事業（平成22年度開始）。延べ300地域以上が登録。
- 窓口：京都市医療衛生センター（北東部・中部・南東部・西部）。
- 支援内容：登録グループへの保護器（捕獲器）貸出、避妊去勢手術の無償実施（京都動物愛護センター）、助言。

## 登録までの流れ
1. 活動グループをつくる：地域住民2名以上。猫が10頭以上の場合は、地域住民2名を含む京都市民3名以上。
2. 町内会等への説明と合意形成：令和6年4月から町内会長の署名は不要になった。申請書に「町内会等へ説明した日付」と「同意を得たことのチェック欄」を記入する。
3. 猫の管理方法を決める：餌場・トイレの場所（正当な権原のある私有地内など）、餌やりの時間・片付け、生息状況の把握（頭数、耳カット済みの有無）。
4. 医療衛生センターへ「まちねこ活動登録申請書（第1号様式）」と「まちねこ活動実施計画書（第6号様式）」を提出。
5. 書類審査と現地調査を経て登録。登録の有効期間は登録日から3年間。

## 登録後
- 地域住民へ周知（参考様式「地域へのお知らせ」）したうえで捕獲。
- 捕獲した猫は京都動物愛護センターへ持込み、手術（手術日は登録後に個別調整）。手術後は元の場所へ戻す。
- 1年ごとに活動状況（頭数の推移など）を報告する。
- 3年で更新申請。活動をやめるときは活動廃止届。

## 令和6年4月改正の要点
- 町内会長の署名・押印の廃止（説明日付＋同意チェックに変更）。
